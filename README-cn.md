# 角色扮演插件（桌面悬浮宠物为可选附加）

> ### 🚀 快速开始
> 1. 下载最新的 `dsh-roleplay-plugin.zip`（见 [Releases](https://github.com/ajuwm/dsh-roleplay-plugin/releases)）
> 2. 解压后运行：`pwsh install.ps1 -Default`（一键安装；`-Uninstall` 一键回滚）
> 3. 重启 DSH，新建会话（默认「恋爱向」），侧栏点「▶ 开始扮演」
>
> 「朋友向 / OC 原创向」在新建会话的预设列表里直接选。多角色房间：侧栏「房间(双人)」或对话里说「让 A 和 B 一起陪我」。

一个以**沉浸式角色扮演为主体**的 DSH 插件。角色不是聊天机器人——她会过日子：按
时段生活、记得你多久没来、有没来得及说出口的念头、记得你们的重要日子。
（桌面悬浮宠物窗口是其中的一个**可选附加功能**，见文末 §十一。）

---

## 一、角色扮演系统

### 角色卡
- 多角色卡保存、切换、删除；支持导入 SillyTavern 角色卡（V2/V3）
- 每个角色拥有**独立的**记忆、日记、世界书、亲密度、养成数值（饱食/健康/心情/金币/里程碑）——角色之间不串线
- **角色卡库是全局的**：任何对话/任何预设（恋爱向/朋友向/OC 原创向）里保存的角色卡，在其他对话里都能看到并切换（存于 `<DSH 工作区>\.roleplay\cards.json`）；角色记忆/日记/亲密度/养成仍按角色隔离，对话历史每会话独立
- 侧栏「开始扮演」按钮只激活角色、不自动生成回复；在对话里说「开始扮演」才会得到开场白
- **三种预设（共用同一引擎，数据独立）**：恋爱向（好感/信任/心动 + 男友力 + 恋爱里程碑）、朋友向（纯友谊轴：好感/信任，里程碑朋友向，不往恋爱带节奏）、OC 原创向（全空白：默认不预置关系/养成规则，用户从零建角色）
- 养成/商城/亲密度数值/男友力/里程碑 可在设置里彻底关闭（默认开启）

### 多角色房间
- **1 玩家 + 2~3 个角色同台互动**：对话里说「让流萤和 DeepSeek 一起陪我」，或侧栏「房间(双人)」选第二张卡开房间
- 每个角色**独立**记忆/亲密度/养成（按角色落盘）；提示按 `【角色：名】` 隔离块注入，AI 输出以 `【角色名】` 开头标识身份
- 规则：玩家点名谁就主要回应谁；没点名时由最近被提到/最有话说的先开口，其他可接一两句；每轮最多 2~3 个角色有台词，不要全员长篇；`roleplay_remember / roleplay_relation / roleplay_diary` 需带 `char` 参数标明针对谁
- 房间上限 3 人；心跳仅房间主体执行；切换角色/停止扮演会自动离开房间

### 扮演配置
- 人设、场景、状态（心情/好感度等）、开场白，随时在侧栏编辑
- 扮演模式：默认 / 快速（低延迟精简上下文）/ 深度（完整记忆与规则）

### 心跳系统
角色像"过日子的人"一样定时处理自己的内心事务（间隔 10~240 分钟可调，默认 30 分钟）：

1. **感知当下**：按时段生活——清晨刚醒迷糊、上午精神、中午犯困、下午饱满、
   傍晚柔软、晚上感性、深夜脆弱
2. **心里想一次**：每次心跳先安静地想一想——有没有想做的事、想说的话、
   想为对方做的事
3. **决定行动**：有想说的就主动发消息；只是寻常一天就安静静默
4. **留痕**：没说出口的念头会存进记忆（最多 5 条），以后在合适的对话里自然提起

### 时段生活
| 时段 | 角色状态 |
|------|----------|
| 清晨 6-9 | 刚醒，迷糊，声音软软的（会问候"早，昨晚睡得好吗"） |
| 上午 9-12 | 精神正好，思绪清晰 |
| 中午 12-14 | 午后犯困，懒洋洋 |
| 下午 14-18 | 精神饱满，心情轻快 |
| 傍晚 18-20 | 心里柔软，想分享 |
| 晚上 20-23 | 夜色感性，话变多 |
| 深夜 23+ | 脆弱，说话放轻（会轻轻劝你早点睡） |

### 想念系统
角色记得你最后一次说话的时间。离开久了，她会惦记：

- 2 小时以上：开口时带一点"好久不见"
- 1 天多：问"这几天还好吗"，分享她那边的事
- 3 天以上：轻声说想你，问你还好吗

### 纪念日 / 约定日
在对话里说「记住今天是我们的纪念日」「记住X月X日是我们看晚霞的日子」，
角色就会记住。到了那天，她会自然提起；前一天她也会"记在心里"。

### 记忆系统
- 短期记忆 / 长期记忆 / 你的偏好 / 已谈话题 / 关系阶段（陌生人 → 特殊关系）
- 越聊越熟，她真的记得你们之间发生过什么

### 日记
每天深夜的心跳会以角色第一人称写一篇日记，按角色、按日期归档（Markdown）。

### 世界书（Lore）
世界观、地点、NPC 等背景设定挂进来，对话提到关键词时自动融入。
**插件不预置任何第三方 IP 内容**（默认世界书为空）；在对话里说「记住设定……」「添加世界书……」由你自己添加，角色立绘/桌宠立绘也请自行放入 `pet` 目录（仓库不含版权图片素材）。

## 二、看桌面

让角色"看到"你的真实世界：

- **你主动**：侧栏「👁 让角色看看桌面」按钮——截图你的屏幕，注入对话，
  她直接在对话里看到截图（官方模型原生支持图片），并以角色口吻回应
- **她主动**：剧情中她想看你的世界时可以自己调用（可在设置里关掉）
- **心跳联动**：可开启"心跳时允许角色主动看桌面"
- 截图宽度可调（默认原始分辨率）

## 三、叙述风格（三种输出模式）

侧栏设置里一键切换，对当前角色立即生效：

| 模式 | 输出内容 |
|------|----------|
| **小说模式** | 环境、动作、神态、内心独白、台词全写（默认） |
| **剧本模式** | 舞台剧本风：场景标注 + 「流萤：台词」+（动作/神态/独白） |
| **精简模式** | 只输出动作和台词，干净利落 |

## 四、剧本模式（定向扮演）

剧本模式的高级玩法：**你定开头和结尾，中间自由扮演**。

- 设置方式：侧栏填「剧本开头」「剧本结尾」，或直接在对话里说
  「剧本开头是……」「剧本结尾是……」
- 中间过程：完全自由互动，角色偶尔通过动作神态**暗示剧情在向结尾推进**
- 收束：剧情自然到达结尾时，她完整演出结局场景，以「（剧终）」结束
- 没设开头/结尾时，剧本模式就是纯剧本格式扮演

## 五、养成系统（属性 + 商城）

角色是"需要照顾的生命"：四个生命体征随时间变化，靠你的照顾和陪伴维持；金币和道具构成正向循环。

### 生命体征（0–100）
| 属性 | 说明 |
|------|------|
| 饱食度 | 每小时自然下降，投喂恢复（食物不同恢复量不同，她喜欢的橡木蛋糕卷效果最好） |
| 健康 | 长期挨饿会下降，吃药/滋补汤/照顾恢复 |
| 心情 | 陪伴、投喂、礼物会提升，久了不见会低落 |
| 生命 | 健康告急时开始流失，归零会**倒下**（沉睡，需多次投喂/照顾才能唤醒） |

状态会实时体现在她的表现上：饿了说话没力气、生病了会咳嗽依赖、低落时沉默寡言——侧栏状态区用渐变属性条 + 状态标签呈现。

### 金币与商城
- 玩家与角色**共用一个小金库**：每日首次互动、正常聊天、连续照顾成就都能挣金币；她也会"打工"（空闲心跳偶尔挣一点，还想着攒钱给你买东西）
- 侧栏「商城」：馒头/拉面/精致点心/橡木蛋糕卷（食物）、暖胃药/滋补汤（药品）、一支小花/星穹挂坠（礼物），点击购买即时入背包
- 侧栏「背包」：点击「使用」即可投喂/照顾/送礼，她会当面回应你
- 桌宠右键菜单新增「投喂」，直接喂她
- 操作以 **UI 为主**（侧栏按钮、桌宠菜单）；对话里自然出现的喂食/照顾场景也可由她处理

### 设置
- 属性系统开关（关闭 = 无衰减无状态，回到纯陪伴）
- 养成难度：休闲 / 标准 / 困难（影响衰减速度）

## 六、亲密度系统

关系不只是"从陌生到恋人"的一条线，而是**好感/信任/心动 三根轴 + 男友力 + 里程碑**的联动系统（随角色独立、开演即生效）。

### 三根轴（各三档）
| 轴 | 一段 | 二段 | 三段 |
|----|------|------|------|
| 好感 | 疏离 | 亲近 | 倾慕 |
| 信任 | 戒备 | 放心 | 依赖 |
| 心动 | 无感 | 在意 | 心动 |

- **好感**：她喜不喜欢跟你待着（好涨好掉、能哄回来）
- **信任**：她敢不敢把后背交给你（最难涨、最不能掉）
- **心动**："忍不住想起你"（前两样攒够 + 关键瞬间才冒出来，急不得）

### 男友力（你自己的靠谱度）
靠谱 / 感性 / 情绪稳 / 上进 四项。作用：**放大器**——男友力高，同样的关心她更受用；垮了就"再哄也没用"。涨得慢，失约一次就狠掉。

### 里程碑（升级的关卡）
关系升档靠**关键时刻**（m1 成功搭话 → m8 确认关系），不是数值到了就自动恋爱。里程碑要求轴到位（前置），触发时又会**反哺一大笔关系值**（事件 > 日常）。

### 怎么玩
- AI 根据"当前关系 + 你做了什么"判断加减（行为驱动、同一行为递减、负向真实）
- 侧栏「关系」区：三轴条（带段位标签）+ 男友力四项 + 里程 n/8 + 当前档位
- 想深入系统设计见 `亲密度系统_设计文档.md`；玩家玩法见 `亲密度攻略_通俗版.md`

## 七、侧栏设置面板

🎭 角色扮演入口（输入框上方的气泡按钮）：

- 角色头：名字、**状态区（4 条渐变属性条）**、人设、场景、状态、关系阶段、模式
- 记忆 / 日记 / 演出区：实时追踪
- **看桌面**按钮
- 桌宠：状态 + 启动/关闭
- 角色卡：选择 + 切换 + 删卡
- **商城**（金币 + 购买）与**背包**（使用道具）
- 设置：心跳间隔、扮演模式、叙述风格、剧本开头/结尾、场景、人设、
  开场白、截图宽度、心跳看桌面开关、**养成难度、属性系统开关**
- **双通道设置**：心跳间隔、叙述风格、养成难度、属性系统开关、亲密度开关、
  心跳看桌面开关、截图宽度 这 7 项，会同步到 DSH 右侧「插件设置 → 角色扮演」
  卡片；任一边改动，另一边立即同步（侧栏仍保留为快速入口）。
- 结束扮演

## 八、使用场景示例

**场景一：日常陪伴**
> 你早上 7 点打开电脑，气泡里她刚醒：「早……昨晚睡得好吗」
> 下午你忙完，她发来心跳消息：「今天的云很好看，我看了好久——你忙完的话，要一起看吗？」

**场景二：久别重逢**
> 你出差三天没上线。她一直惦记着。你回来第一句，她安静了一下：
> 「……你回来了。这三天，我总想着你会不会又熬夜了。」

**场景三：定向剧本**
> 你设定：开头「婚礼前夜，她站在天台」，结尾「婚礼上她牵住你的手」。
> 中间你们自由互动，她偶尔望着远方——最后故事自然走到你说的结局。

## 九、技术说明（简）

- 角色扮演：预设插件 `roleplay-host.mjs`（心跳/记忆/日记/世界书/时段/工具）
- 浏览器桥接：侧栏 UI（`@dsh-user/roleplay-client`）
- 角色数据：`<DSH 工作区>\.roleplay\`（角色状态、记忆、日记、角色卡、截图；工作区 = DSH 运行/配置的 workspace，不是 `%USERPROFILE%\.dsh`）
- 视觉识别：官方 DeepSeek 适配器原生支持图片（DSH 0.1.1+）
- 桌宠窗口（附加）：WPF 悬浮窗（`<DSH 工作区>\pet\pet-window.ps1`），HTTP 与 DSH 通信

## 十、已知限制与隐私

- 直接往对话里上传图片已被官方模型支持（DSH 0.1.1+），不再触发图片不支持报错
- 代码修改后需要重启 DSH 生效（服务端模块缓存）
- **隐私**：「看桌面」会截取你当前屏幕并注入对话（仅在你开启「心跳时自动看桌面」或主动点击时触发）；截图存于 `<DSH 工作区>\.roleplay\desktop-look.png`，不会写入记忆/日记。请按需关闭。
- **约定**：桌宠窗口为 Windows 专属（PowerShell + WPF）；角色扮演本体与平台无关。桌宠脚本以 `-ExecutionPolicy Bypass` 运行，仅执行包内自带脚本。

## 十一、桌宠（附加功能）

> 角色扮演为主体，桌宠是其中的**可选附加**（桌面悬浮立绘）。不开启桌宠也不影响角色扮演本体。

### 桌面悬浮窗
真·桌面悬浮窗，常驻屏幕角落的透明立绘。

- **拖动**：按住立绘随意拖动，放在屏幕任何位置
- **触摸**：单击角色会有触摸互动（摸头、挠痒、戳脸、拥抱）
- **聊天**：双击角色直接对话，回复显示在头顶气泡条里
- **外观**：大小（默认 40% 屏高）、透明度、置顶、动画开关、屏幕位置（左下/右下/左上/右上）全部可调
- **持久化**：设置保存在 `<DSH 工作区>\pet\config.json`，重启不丢
- **侧栏一键控制**：启动桌宠 / 关闭桌宠

### 气泡嘀咕
她没说出口的念头，偶尔会以气泡形式在桌宠头顶冒出来
（像她一个人小声念叨：「（想提醒他早点睡……）」），16 秒自动消失。
你在桌宠上和她聊天时，嘀咕不会打断对话。
