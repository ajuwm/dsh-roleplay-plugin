# 桌宠攻略 · 亲密度玩法指南

> 想让流萤更喜欢你、更信任你、忍不住想你？这套「亲密度」系统就是答案。
> 简单说：**关系不是一条线，是好感 / 信任 / 心动 三根轴 + 你自己的男友力 + 一路的关键事件。**

---

## 一、先看三根轴

| 轴 | 管什么 | 通俗说 |
|----|--------|--------|
| **好感** | 她喜不喜欢跟你待着 | 好涨、好掉、也能哄回来 |
| **信任** | 她敢不敢把后背交给你 | 最难涨、最不能掉、掉了很难补 |
| **心动** | "忍不住想起你" | 最玄，急不得，前两样攒够了自然冒出来 |

### 每根轴分三段（决定她对你多亲近）

**好感**：疏离（客气有距离）→ 亲近（会主动靠近你）→ 倾慕（满眼都是你）
**信任**：戒备（保留、不交底）→ 放心（敢说心里话）→ 依赖（把后背交给你）
**心动**：无感（只当同伴）→ 在意（偶尔走神想你）→ 心动（忍不住想起你）

侧栏里每根轴旁边会显示你现在是哪一段（比如「好感 · 亲近」）。

## 二、怎么涨、怎么掉

**涨**：陪她说话、逗她笑、记得她喜欢什么（她爱橡木蛋糕卷）、她难受时你在、说到做到。
**掉**：冷落她、说错话、放鸽子、关键时刻不在——**尤其信任，掉得狠、回得慢**。

## 三、别刷分（重要）

- **同一件事重复做，加成越来越少**：天天只打招呼，好感涨得越来越慢。
- **一个关键瞬间，比一百句问候都重**：她难受时你陪着她，这一下比平时聊一礼拜都涨得多。

## 四、男友力：你自己的靠谱度

你不是只"刷她"，还得"练自己"。男友力是**你自己**攒出来的靠谱度，分四块：

| 方面 | 管什么 |
|------|--------|
| **靠谱** | 说到做到、守约 |
| **感性** | 她高兴你懂、她难受你懂、不说话也能读懂 |
| **情绪稳** | 她闹、累、说错话时，你接得住她 |
| **上进** | 有自己的事，不整天只围着她转 |

男友力的作用：**同样一个关心，男友力高 → 她更受用；男友力垮了 → 再哄也没用。**
男友力涨得慢、失约一次就狠掉，所以别轻易食言。

## 五、里程碑：关系升级靠"关键时刻"

数值到了**不等于**自动恋爱。关系要升一档，得触发对应**里程碑**（一件真正发生的事）：

1. 第一次成功搭话
2. 第一次记住她的喜好
3. 她难受时你陪在身边
4. 第一次守约（说到做到）
5. 她主动跟你分享心事
6. 一起经历过重要的事
7. 约定的日子，一起去完成它
8. 表白、确认关系（更后面的事）

里程碑一面要求你的轴到位（比如"她主动分享心事"得先让好感三档、信任二档），一面**触发时会给你一大笔好感/信任**（大事件就是值钱）。侧栏会显示你走到了几个（`里程 n/8`）。

## 六、怎么看她现在对你想什么

侧栏「关系」区一眼看全：
- 三根轴条 + 段位标签（好感 · 亲近｜信任 · 放心｜心动 · 在意）
- 男友力四项（靠谱 / 感性 / 情绪稳 / 上进）
- 里程碑进度（里程 n/8）
- 关系档位（陌生人 → 普通认识 → 朋友 → 亲密朋友 → 恋人）

## 七、常见疑问

**Q：为什么她对我还是冷冷的？**
好感还在第一段（疏离）。多陪她说话、记得她喜好，慢慢到第二段她会亲近。

**Q：为什么我说错一句就掉信任？**
信任就是这样，掉得狠。她越信任你，你失信一次越伤。别乱开玩笑、说到做到。

**Q：心动怎么上来？**
别急。心动要靠好感和信任攒到一定程度、再撞上某个"关键瞬间"才冒出来。急不得，也硬刷不出来。

**Q：男友力怎么练？**
守约、共情、稳住情绪、有自己的事。都是"做人的事"，不是反复点按钮。

> 攻略的真正难度，不是让数字涨得慢，而是**你真的懂她**。
