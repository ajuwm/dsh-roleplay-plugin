# 角色扮演插件 UI 设计规范(v1.5 起)

所有新增/重做的 UI(对话侧边栏、便签、小游戏卡、好感度进度、桌宠角标)必须遵守本规范,
保证"风格一致、美观"。现有 UI(侧栏 rp-sb、按钮 rp-dock-btn、折叠卡 rp-pg-card)即为基准。

## 1. 设计语言

- **玻璃深色**:面板底色 `rgba(18,20,26,.97)`(浮层)/ `rgba(255,255,255,.055)`(面板内卡片),
  描边 `rgba(128,128,128,.16)`(面板边)/ `rgba(255,255,255,.10)`(卡片边),内高光
  `box-shadow:0 1px 0 rgba(255,255,255,.06) inset`。
- **浅色主题**:面板 `rgba(240,241,244,.98)`、卡片 `rgba(255,255,255,.78)`、
  描边 `rgba(0,0,0,.08)`、阴影 `0 6px 24px rgba(0,0,0,.08)`。
- **圆角三档**:卡片 18px / 控件 10px / 胶囊 999px。
- **强调色**:青蓝(`rgba(120,160,220,*)` 系,按钮/角色气泡)、蓝焦点 `#0a84ff`(深)/`#007aff`(浅)、
  绿成功 `rgba(120,200,140,*)`、红危险 `rgba(220,120,120,*)`。
- **字体**:系统字体栈继承;面板标题 14px/700,区块标题 11px/间距 1.5px/不透明度 .5,
  正文 13px 行高 1.55,弱文本 12px 不透明度 .6。

## 2. 组件库(全部沿用现有类名前缀 rp-)

| 组件 | 类名 | 规则 |
|---|---|---|
| 浮层面板 | `rp-sb` / `rp-chat` | 右侧 fixed,宽度固定,左描边+投影,头部/内容/底部三明治 |
| 胶囊按钮 | `rp-dock-btn` | 描边+弱底,悬浮加深,激活态 `rp-open` |
| 折叠卡 | `rp-pg-card` | 圆角12,一档描边,bg layer-3,展开 layer-2(官方插件卡同款) |
| 属性条 | `rp-stat-bar`(渐变) | 顶部分区状态条,渐变显数值 |
| 进度条 | `rp-progress`(细 4px) | 距下一档百分比,填充用强调色渐变 |
| 消息气泡 | `rp-chat-msg(-role/-user/-plugin/-sys)` | 角色=青蓝玻璃,用户=灰玻璃,插件=斜体小字,系统=居中弱字 |
| 纸条窗 | `rp-note`(WPF) | 玻璃卡 + 📌 角标,圆角12,拖动任意位置 |
| 状态圆点 | `rp-chat-dot` | 8px 圆,绿=在线,灰=未开演 |

## 3. 强制纪律

1. 新增样式一律追加到 `lib/client.js` 的 `style.textContent` 数组(同一 `<style data-plugin>` 标签),
   不引入第二个 style 标签、不内联散落样式。
2. 颜色/圆角/阴影只允许使用本规范 token,不引入第二套配色。
3. 深浅主题**必须成对**:`body:not([data-ds-dark-theme])` 覆盖写全,防浅色主题下不可读。
4. 交互反馈:悬浮 0.12s 提亮,点击 0.16s 过渡,出入场 0.45s 滑入(translateX)。
5. 文本:中文为主,弱提示用 12px 斜体或 opacity 区分,不用大红大绿。
6. 所有新 UI 与现有侧栏同 slot 注册,卸载即移除(`ctx.effect` 清理)。
