# 好感度(亲密度)系统 · 手感验收表(v1.5.5)

> 本表描述当前数值手感,供您实测后反馈"哪里不对"——我们按您的体验标定下一轮数值。
> 原则:**行为重于频率、事件重于日常、负向要真实、同一行为重复递减**;数值只作为表征,不干预 AI 的剧情判断。

## 1. 三维好感(0~100,各三档)

| 轴 | 档位 | 说明 | 关键门槛 |
|---|---|---|---|
| 好感 favor | 疏离(0-33) / 亲近(34-66) / 倾慕(67-100) | 好感的直观积累 | 里程碑/阶段主要看它 |
| 信任 trust | 戒备(0-33) / 放心(34-66) / 依赖(67-100) | 靠守约、陪伴、关键时刻在场上升;食言/缺席**真实地掉** | 「心动」需要它到位 |
| 心动 heart | 无感(0-33) / 在意(34-66) / 心动(67-100) | **锁定机制**:favor+trust 均到二档前,心动不允许正增(engine 会拒绝并提示) | 心动≥三档 = 心动事件池解锁 |

## 2. 增益参考(角色调用 roleplay_relation 时的区间)

| 行为 | 建议增量 |
|---|---|
| 举手之劳 / 礼貌寒暄 | favor +0~1 |
| 被夸奖 / 分享日常 / 一起活动 | favor/trust +1~2 |
| 记住她喜好 / 守约 / 关键时刻陪伴 | trust +2~4 |
| 约会 / 情感表白 / 送礼物 | favor+3~5, heart+1~3 |
| 食言 / 关键时刻不在 | trust -2~4(真实) |
| 冷战 / 沉默多日 | trust -1~2·天 |

- 同一行为**连续发生递减**:第 1 次 ×1.0 → 第 2 次 ×0.6 → 第 3+ 次 ×0.3(重复 Dim 独立按轴判定)
- 久别衰减:48h 未互动后每 24h trust -1,封顶 -5(回来互动后重置)

## 3. 倍增器

- **男友力**(靠谱/感性/情绪稳/上进,各 0~100)= 放大器:均值决定系数 `0.6 + 0.8×(均值/100)`:
  - 均 50 → ×1.0;均 25 → ×0.8;均 75 → ×1.2;均 100 → ×1.4
  - 负增量的缩放不同(负向更敏感:系数 `1.6 - 0.6×系数` → 低男友力时负向更狠)
- **relPace 玩家自选**:慢热 ×0.5 / 正常 ×1 / 快速 ×1.5(只缩放剧情评估的正负增量,档位阈值/里程碑不变)

## 4. 里程碑(8 个,达标即触发并反哺)

恋爱向:`m1 第一次搭话(m1→favor6)→ m2 记住喜好(favorTier2)→ m3 陪伴难受(trustTier2)→ m4 守约(trustTier2)→ m5 分享心事(favor3+trust2)→ m6 共同经历(favor3+trust3)→ m7 约定同行(trust3+heart2)→ m8 确认关系(全三档)`
朋友向:无心动/男友力轴,m8=知己。里程碑奖励在触发时按表一次性反哺(trigger 时校验档位,不足则提示"她心里还差一点")。

## 5. 关系阶段(行为表现的锚)

| 阶段 | 条件 | 档位行为(称呼/语气/主动度/互动) |
|---|---|---|
| 陌生人 | 0 里程碑 | 「您」/拘谨/只回应/点头问好 |
| 普通认识 | 1 里程碑+好感2档 | 「你」/客气玩笑/偶尔问候 |
| 朋友 | 3 里程碑+好感2+信任2 | 「你」+名字/自然话多/分享日常 |
| 亲密朋友 | 5 里程碑+好感3+信任2 | 亲昵称呼/黏人撒娇/主动邀约 |
| 特殊关系 | 7 里程碑+全三档 | 专属称呼/亲昵任性/小惊喜 |

## 6. 邀您实测清单(每题一句话反馈即可)

1. 从 0 到「普通认识」的节奏:几轮对话?感觉快/慢?(正常节奏:~3-5 次关键互动)
2. 心动解锁时机:好感+信任到二档后,心动是否自然出现?
3. 吃醋/食言场景:trust 掉的幅度是否"疼"?
4. 里程碑触发:是否出现过"她明明达标了却不触发"(反馈:哪一步差多少)?
5. 档位行为:称呼/语气变化是否明显?该更黏/更含蓄吗?
6. 心动事件(心跳):出现频率合适吗(现在每心跳 40% 概率)?

> 每项反馈会落到具体参数(增量区间/倍数/里程碑门槛)再标定,不一次性大改。
