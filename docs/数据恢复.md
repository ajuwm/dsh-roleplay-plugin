# 数据备份与恢复(重要!)

角色扮演的所有重要数据(.roleplay/.roleplay-friend/.roleplay-oc 下的角色卡库、当前状态、记忆、日记、人格档案、剧情档案)
现在有**三层备份 + 用户级镜像**,正常情况下数据**不再单点**。

## 备份在哪

| 层 | 位置 | 内容 | 保留 |
|---|---|---|---|
| L1 写盘前 | `<数据根>/<file>.bak` | 单文件写坏前的上一版 | 最新 1 版 |
| L2 每日快照 | `<工作区>/.roleplay-backup/<dataRoot>/<日期>/` | 当天全部数据(准实时,同日写入不丢) | 最近 3 天 |
| L4 用户级镜像 | `%USERPROFILE%\.dsh\.roleplay-backups/<dataRoot>/<日期>/`(环境变量 `DSH_ROLEPLAY_BACKUP_DIR` 可改) | L2 的跨工作区副本 | 最近 3 天 |

⚠️ **请勿删除 `.roleplay-backup` 或 `.roleplay-backups` 目录**——那是救命备份;排查/修复时也请不要动 `.roleplay*` 数据目录。

## 自动恢复

- 数据根(如 `.roleplay`)整体缺失/被删 → **引擎启动自动从最近快照补回**(只补缺失文件,不覆盖现存)
- 工作区数据根缺失且本地备份也走了 → **宿主桥接(每 60s)自动从用户级镜像回流整目录**
- 侧栏「设置 → 💾 立即备份数据」可随时手动做一份当日快照

## 手动恢复(自动失败时)

1. 复制 `%USERPROFILE%\.dsh\.roleplay-backups\.roleplay\<最近日期>\` 下全部文件 → `<工作区>\.roleplay\`
2. 或复制 `<工作区>\.roleplay-backup\.roleplay\<最近日期>\` 同名目录
3. 重启 DSH,进入角色扮演会话,数据即回

## 建议

- 重要剧情节点(确认关系、里程碑)顺手点一次「立即备份数据」
- 定期把 `%USERPROFILE%\.dsh\.roleplay-backups` 复制到移动盘/网盘(这是唯一跨机器手段)
